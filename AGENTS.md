# Architecture rules

- Strategy previews use the shared feature gate for `ai.backtests` and the shared upgrade dialog in StrategyBuilderCard; the server remains authoritative so both Technical Analysis and Strategy Lab handle denied access consistently.
- Public plan descriptions share presentation-only bullets and a comparison catalog across pricing, billing and upgrade surfaces; derive annual FAQ prices from plan definitions, verify monthly AI quotas against the AI resolver and live plan rows, and never use marketing facts to authorize access.
- Apple purchases use RevenueCat with authenticated Vela UUID identities; trusted server reconciliation writes separate Apple billing records, and shared feature/AI resolvers combine providers without overwriting Stripe state. Native purchase surfaces never expose website checkout.
- Public investor calculators run locally with pure tested calculation modules; disclose compounding, contribution timing, costs and exclusions, and keep guide routes outside authentication gates for free access.
